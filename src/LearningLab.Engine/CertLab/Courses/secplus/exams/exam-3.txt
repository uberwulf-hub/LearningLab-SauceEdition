@firewall p01 | Security operations | 6
A branch office has three networks behind one firewall: a guest Wi-Fi for visitors, the staff LAN and a server VLAN with the file server. Write the firewall rules. Name lookups (DNS) do not pass through this firewall, so leave them out. Rules are read top to bottom; the first rule that matches decides; anything no rule matches is denied.
rows 6
addr Internet = 0.0.0.0/0
addr Guest Wi-Fi = 10.99.0.0/24
addr Internal networks = 10.20.0.0/16
addr Staff LAN = 10.20.1.0/24
addr IT admin PC = 10.20.1.10/32
addr File server = 10.20.5.10/32
ports 22, 80, 443, 445, 3389, 8080
test allow | 10.99.0.20 -> 198.51.100.80 | 443/TCP | guests on the Wi-Fi can open websites on the internet over HTTPS
test deny | 10.99.0.20 -> 10.20.5.80 | 443/TCP | guests cannot reach anything on the internal networks, not even the intranet site at 10.20.5.80 over HTTPS
test deny | 10.99.0.20 -> 198.51.100.80 | 80/TCP | guests may use HTTPS only, not plain HTTP
test allow | 10.20.1.33 -> 10.20.5.10 | 445/TCP | staff on the LAN can open shared folders on the file server (SMB)
test allow | 10.20.1.33 -> 198.51.100.80 | 443/TCP | staff on the LAN can open websites over HTTPS
test allow | 10.20.1.10 -> 10.20.5.10 | 3389/TCP | the IT admin PC can use Remote Desktop on the file server
test deny | 10.20.1.33 -> 10.20.5.10 | 3389/TCP | other staff PCs cannot use Remote Desktop on the file server
test deny | 203.0.113.66 -> 10.20.5.10 | 445/TCP | nobody on the internet can reach the file shares
rule DENY | Guest Wi-Fi | Internal networks | Any | Any
rule ALLOW | Guest Wi-Fi | Any | 443 | TCP
rule ALLOW | IT admin PC | File server | 3389 | TCP
rule ALLOW | Staff LAN | File server | 445 | TCP
rule ALLOW | Staff LAN | Any | 443 | TCP
! The guest deny must come first: the next rule lets guests reach Any address on 443/TCP, and Any includes the intranet server at 10.20.5.80, so with the rows the other way round a guest could reach the internal network. Guests then get HTTPS to anywhere else; plain HTTP (80) matches no rule and falls to the implicit deny. Remote Desktop (3389) is allowed only from the IT admin PC's own address, so other staff PCs are denied by default. Staff get SMB (445) to the file server only, and HTTPS to Any. No rule lets anything from the internet in, so the implicit deny keeps the file shares away from outside addresses; no extra deny row is needed for that.

@risk p04 | Security program management and oversight | 6
A logistics company's warehouse management system (servers, software and the work to rebuild them) is valued at $250,000. The security team estimates that a ransomware attack would damage about 40% of that value, and expects such an attack about once every two years. A vendor offers endpoint detection and response (EDR) plus immutable backups for $12,000 per year. With them, an attack would still happen about as often, but it would damage only about 10% of the value, because the systems could be cleaned and restored quickly.
calc sle | Single loss expectancy (SLE) today, in dollars | = 250000 * 0.4
calc ale | Annualized loss expectancy (ALE) today, in dollars per year | = 250000 * 0.4 * 0.5
calc net | Net yearly saving from the vendor's offer (the ALE removed minus the yearly cost), in dollars | = (250000 * 0.4 * 0.5) - (250000 * 0.1 * 0.5) - 12000
? residual | After buying the offer, an expected loss of $12,500 a year remains. What is this remaining risk called?
- Inherent risk
+ Residual risk
- Risk appetite
- Risk threshold
? avoid | Most ransomware at this company has entered through an old remote access portal that only a few drivers use. Management decides to shut the portal down for good and give those drivers another way to work. Which risk strategy is this for the portal?
- Transference
- Acceptance
- Mitigation
+ Avoidance
! SLE = asset value x exposure factor = $250,000 x 0.4 = $100,000. Once every two years is an ARO of 0.5, so ALE = $100,000 x 0.5 = $50,000 a year. With the controls the exposure factor falls to 0.1: SLE $25,000, ALE $12,500 a year. The offer removes $37,500 of expected loss a year and costs $12,000, a net saving of $25,500, so it is worth it. The risk left after controls is residual risk; inherent risk is the risk before any controls. Stopping the activity that brings the risk (the portal) is avoidance; EDR and backups are mitigation, insurance would be transference.

@match p05 | Security architecture | 6
Match each need to the technology or design that meets it BEST.
columns Need | Technology or design
= Keep a factory's controllers on a network with no connection of any kind to other networks -> Air gap
= Change paths and traffic rules for the whole network from one central controller, in software, instead of on each switch -> Software-defined networking (SDN)
= Spread visitors to a website across four identical web servers and skip any server that stops answering -> Load balancer
= Let twenty branch offices use several internet links each, with traffic steered over the best link and managed centrally -> SD-WAN
= Inspect requests to a web application and block SQL injection and cross-site scripting -> Web application firewall (WAF)
= Run the software of an infusion pump that must react within a few milliseconds every time -> Real-time operating system (RTOS)
= Give a small shop one box that combines firewall, antivirus, web filtering and VPN -> Unified threat management (UTM)
x Honeynet
x Cold site
! An air gap means no physical or wireless link at all; it is the strongest isolation. SDN separates the control plane from the switches so the network is programmed centrally. A load balancer shares requests between servers and uses health checks to skip failed ones. SD-WAN manages many links between sites and picks the best path. A WAF understands web requests (layer 7) and blocks attacks on applications. An RTOS guarantees response times, which medical and industrial devices need. A UTM packs several security functions into one appliance, which suits a small site. A honeynet is a set of decoys and a cold site is an empty recovery site; neither meets any of these needs.

@choice q006 | General security concepts | 1
Auditors worry that an attacker could record a bank's encrypted web traffic today, steal the server's private key next year, and then decrypt the old recordings. Which change prevents this?
+ Use only TLS cipher suites with ephemeral key exchange (ECDHE), which give perfect forward secrecy
- Replace the 2048-bit RSA key with a 4096-bit RSA key used for key exchange
- Turn on OCSP stapling
- Pin the server's certificate in the mobile app
