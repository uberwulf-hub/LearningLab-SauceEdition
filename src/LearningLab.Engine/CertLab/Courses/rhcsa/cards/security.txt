The umask is 027. Which modes do new files and folders get? :: files 640, folders 750
Which umask gives new files 600 and folders 700? :: 077
Set the umask 027 for every user who logs in :: a file /etc/profile.d/umask.sh with the line umask 027

sshd_config setting that forbids root logins over ssh :: PermitRootLogin no (and check /etc/ssh/sshd_config.d: the first value wins)
sshd_config setting that allows only key logins :: PasswordAuthentication no
Make sshd read its changed settings :: `systemctl restart sshd`
