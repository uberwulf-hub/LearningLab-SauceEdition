@task t01 | Running systems | 15 | server2
The root password of server2 is unknown. Interrupt the boot process of server2 and set the root password to `{rootpw}`. Leave SELinux enforcing.
@check server2 | root can log in with the new password
certlab-check password root '{rootpw}'
@check server2 | the machine boots normally and SELinux is enforcing
certlab-check booted && test "$(getenforce)" = Enforcing
@solution server2
#reset
#key e
#key Down Down Down End
#type  rd.break
#key Ctrl+X
mount -o remount,rw /sysroot
chroot /sysroot
echo '{rootpw}' | passwd --stdin root
touch /.autorelabel
exit
exit
#password {rootpw}
@explain
Press the machine's reset button. At the boot menu press e (the key alone, no Enter), go down to the line that starts with linux, press End, type a space and rd.break, and boot with Ctrl+X. In the initramfs shell /sysroot is the real root file system, mounted read-only: remount it read-write, chroot into it, change the password, and create /.autorelabel. The relabel matters: passwd writes a new /etc/shadow without an SELinux label (no policy is loaded in the initramfs), and with SELinux enforcing nobody could log in until the file is relabelled. Then leave the chroot and the initramfs shell with exit twice.
@endtask

@task t13 | Shell scripts | 20 | server1
Write the script /usr/local/bin/{script}. It takes the name of a file as its only argument and creates one user for every line of that file. Run without an argument, it prints `Usage: {script} FILE` and exits with status 1. A user that already exists is skipped with the message `NAME exists`.
@check server1 | without an argument: the usage line and exit status 1
out=$(/usr/local/bin/{script} 2>&1); rc=$?; test $rc -eq 1 && echo "$out" | grep -q "Usage: {script} FILE"
@check server1 | it creates the users listed in a file
printf 'grader1\ngrader2\n' > /tmp/grader.list; /usr/local/bin/{script} /tmp/grader.list >/dev/null 2>&1; id grader1 && id grader2
@check server1 | an existing user is reported
printf 'root\n' > /tmp/grader2.list; /usr/local/bin/{script} /tmp/grader2.list 2>&1 | grep -q 'root exists'
@solution server1
cat > /usr/local/bin/{script} <<'EOF'
#!/bin/bash
if [ $# -ne 1 ]; then
    echo "Usage: {script} FILE"
    exit 1
fi
while read -r name; do
    if id "$name" &>/dev/null; then
        echo "$name exists"
    else
        useradd "$name"
    fi
done < "$1"
EOF
chmod +x /usr/local/bin/{script}
@explain
$# is the number of arguments. while read -r name; do ... done < "$1" reads the file line by line. id NAME succeeds when the user exists. Remember the #! line and the execute permission (chmod +x).
@endtask
