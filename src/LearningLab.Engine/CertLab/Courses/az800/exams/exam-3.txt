@task t01 | AD DS | 4 | DC1
Members of **IT Admins** must use passwords of at least **{len}** characters, while the rest of the domain keeps its policy. Create the fine-grained password policy **Admins-{n}** with precedence **10** and apply it to the group.
@check admin | the policy and who it applies to
pso["Admins-{n}"].appliesto has "IT Admins"
passwordpolicy(user=arivera).minlength == {len}
@check admin | others keep the domain policy
passwordpolicy(user=bcole).minlength == 7
@solution DC1
New-ADFineGrainedPasswordPolicy -Name Admins-{n} -Precedence 10 -MinPasswordLength {len} -ComplexityEnabled $true
Add-ADFineGrainedPasswordPolicySubject -Identity Admins-{n} -Subjects "IT Admins"
@explain
Fine-grained password policies (password settings objects) apply to users and global security groups; when several apply, the lowest precedence number wins, and one linked to the user directly beats those through groups.
@endtask

@task t02 | Group Policy | 4 | admin
Anyone who signs in to a PC in the **Workstations** OU must have the command prompt blocked, and must not get the user settings of the GPOs linked to their own OU. Create the GPO **Kiosk desktop {n}** for this and link it to Workstations.
@check admin | the kiosk settings apply to a staff member on CL1
rsop(computer=CL1, user=bcole).setting["NoCmd"] == Enabled
rsop(computer=CL1, user=bcole).loopback == Replace
@check admin | the staff OU's user settings don't
rsop(computer=CL1, user=bcole).setting["NoRegedit"] == "Not configured"
@solution admin
gpo new "Kiosk desktop {n}"
gpo set "Kiosk desktop {n}" setting=NoCmd state=Enabled
gpo set "Kiosk desktop {n}" setting=Loopback state=Enabled value=Replace
gpo link "Kiosk desktop {n}" Workstations
@explain
Loopback processing (a computer setting) applies user settings from GPOs linked to the computer's OU. Replace ignores the user's own GPOs (here Staff desktop's registry tools setting); Merge would apply both, the computer's side winning conflicts.
@endtask

@task t03 | Networking | 4 | DC1
Create a reverse lookup zone for the branch subnet **10.20.0.0/24**, stored in Active Directory and replicated to all DNS servers in the domain, and add the pointer record for **dc2.corp.example** (10.20.0.11).
@check admin | the zone on both DCs
dns(DC2).zone["0.20.10.in-addr.arpa"].adintegrated == Yes
dns(DC1).zone["0.20.10.in-addr.arpa"].scope == Domain
@check admin | the pointer resolves
resolve(client=CL1, name=10.20.0.11, type=PTR) == dc2.corp.example
@solution DC1
Add-DnsServerPrimaryZone -NetworkId 10.20.0.0/24 -ReplicationScope Domain
Add-DnsServerResourceRecordPtr -ZoneName 0.20.10.in-addr.arpa -Name 11 -PtrDomainName dc2.corp.example
@explain
-NetworkId builds the zone name (0.20.10.in-addr.arpa); the Domain replication scope stores it in the DomainDnsZones partition so every DNS server that is a DC in the domain loads it. The PTR record's name is the last octet.
@endtask

@task t04 | File and storage | 4 | FS1
The archive volume **E:** on FS1 holds many copies of the same files. Install Data Deduplication, enable it on E: for general file server use, and run an optimization job now (waiting for it to finish).
@check admin | deduplication is on and saving space
dedup(FS1, E).enabled == Yes
dedup(FS1, E).usage == Default
dedup(FS1, E).savedgb > 1
@solution FS1
Install-WindowsFeature FS-Data-Deduplication
Enable-DedupVolume -Volume E: -UsageType Default
Start-DedupJob -Volume E: -Type Optimization -Wait
@explain
Default is the usage type for general purpose file servers (HyperV and Backup are for VDI and backup targets). Only files older than the minimum file age (3 days by default) are optimized, which these archive files are. Deduplication can't be enabled on the system volume.
@endtask

@task t05 | File and storage | 4 | FS1
Create the domain-based namespace **\\corp.example\Files** (Windows Server 2008 mode) hosted on FS1, with its root in a new share **Files** for the folder **D:\DfsRoots\Files**, and a namespace folder **Sales** that points to **\\FS1\Sales**.
@check admin | the namespace and its folder
namespace["\\corp.example\Files"].folders has Sales
namespace["\\corp.example\Files"].targets["Sales"] has "\\FS1\Sales"
@check admin | the path leads to the Sales share
dfsresolve("\\corp.example\Files\Sales") == "\\FS1\Sales"
@solution FS1
Install-WindowsFeature FS-DFS-Namespace -IncludeManagementTools
New-Item -Path D:\DfsRoots\Files -ItemType Directory
New-SmbShare -Name Files -Path D:\DfsRoots\Files -ReadAccess Everyone
New-DfsnRoot -Path \\corp.example\Files -TargetPath \\FS1\Files -Type DomainV2
New-DfsnFolder -Path \\corp.example\Files\Sales -TargetPath \\FS1\Sales
@explain
A domain-based namespace's root target is a share on a namespace server that runs the DFS Namespaces role service; DomainV2 is "Windows Server 2008 mode" (access-based enumeration, more folders). Folders point users to existing shares.
@endtask

@case cs3 | Pinecrest School District
## Overview
Pinecrest School District (made up) runs a district office and six schools. The IT department of five people manages 3,000 student and staff accounts and 1,800 shared PCs.

## Existing environment
The forest pinecrest.example has one domain. The district office hosts two domain controllers, DNS and DHCP. Each school has a Windows Server 2022 Hyper-V host with a domain controller VM and a file server VM. Student accounts are in OU=Students, staff accounts in OU=Staff, and PCs in one OU per school. Staff use Microsoft 365; Microsoft Entra Connect Sync runs on a single server at the district office with password hash synchronization.

## Requirements
- If the Microsoft Entra Connect server fails, another server must be able to take over synchronization quickly.
- Teachers must not be able to change Group Policy, but the help desk must be able to edit the GPOs of the schools' PC OUs only.
- Students on any PC must not reach Control Panel; staff on the same PCs must.
- When the school's Hyper-V host restarts for updates, each school's domain controller VM must come back by itself afterwards, resuming where it left off. Checkpoints must never be applied to the DC VMs in production.
- The district wants to update all servers, including the schools' hosts, from Azure without opening inbound ports.

## Technical constraints
Minimise cost and the number of new servers.
@endcase

@choice q19 | Networking | 1
