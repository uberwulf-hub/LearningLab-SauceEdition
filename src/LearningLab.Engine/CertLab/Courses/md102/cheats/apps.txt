## Win32 apps
IntuneWinAppUtil.exe -c source -s setup.exe -o output :: package a setup folder as .intunewin
Install / uninstall command :: must be silent (/S, /quiet, /qn, /silent)
msiexec /i app.msi /qn :: silent MSI install
Install behavior System :: all users, admin rights (Program Files)
Install behavior User :: the user's context, no admin rights
Return codes :: 0 and 1707 success, 3010 soft reboot, 1641 hard reboot, 1618 retry
Requirements :: architecture, minimum OS, disk, memory, CPU, custom rules; else Not applicable
Detection: MSI :: product code {GUID}, optional version
Detection: File :: a file or folder exists (or date, version, size)
Detection: Registry :: a key or value exists (or its value)
Detection: script :: exit 0 with output = detected
0x87D1041C :: not detected after a successful install: wrong detection rule
1603 :: MSI fatal error (for example a missing prerequisite: add a dependency)
Dependency :: installed first, no assignment needed
Supersedence :: the new app replaces the old where the new one is assigned; Uninstall previous version removes it first
