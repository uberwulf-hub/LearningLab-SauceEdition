## BitLocker

Allow Standard User Encryption = Enabled :: silent for non-admin users
Startup PIN required :: not silent: the user must choose it
XTS-AES 128-bit :: default OS drive method (256-bit stronger)
Save recovery information to Microsoft Entra ID :: back up the key
Do not enable BitLocker until recovery information is stored :: key first, then encryption
Configure Recovery Password Rotation :: replace used keys; allows the key rotation action
