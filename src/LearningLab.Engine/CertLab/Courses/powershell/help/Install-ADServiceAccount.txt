SYNOPSIS: Installs a managed service account on this computer so services can run as it.
DESCRIPTION:
Run Install-ADServiceAccount on the server that will use the account (it needs the Active Directory module there, from RSAT-AD-PowerShell). It checks that this computer may retrieve the password and gets it ready.
It fails with "The provided context did not match the target" when the computer isn't in the account's PrincipalsAllowedToRetrieveManagedPassword list (or its group membership isn't in its token yet).
Afterwards, set the service to log on as CORP\gmsa-web$ with an empty password.
PARAMETER Identity:
The account, such as gmsa-web. Position 0, and takes pipeline input.
PARAMETER Force:
Installs without asking.
EXAMPLE: Install-ADServiceAccount gmsa-web
On SRV1: installs the gMSA.
EXAMPLE: Install-ADServiceAccount gmsa-web; Test-ADServiceAccount gmsa-web
Installs it and checks that it works (True).
RELATED: Test-ADServiceAccount, New-ADServiceAccount, Set-ADServiceAccount
