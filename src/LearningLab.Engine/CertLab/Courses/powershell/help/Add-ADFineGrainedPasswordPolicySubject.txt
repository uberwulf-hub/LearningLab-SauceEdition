SYNOPSIS: Applies a fine-grained password policy to users or groups.
DESCRIPTION:
A fine-grained password policy does nothing until it has subjects. Subjects can be users or global security groups. OUs can't be subjects; to cover an OU, use a group that holds its users (a shadow group).
PARAMETER Identity:
The policy. Position 0, and takes pipeline input.
PARAMETER Subjects:
The users or groups to apply it to. Position 1.
PARAMETER PassThru:
Returns the policy after the change.
EXAMPLE: Add-ADFineGrainedPasswordPolicySubject AdminsPSO -Subjects "IT Admins", "Domain Admins"
The administrators' groups get the strict policy.
EXAMPLE: Get-ADUserResultantPasswordPolicy arivera
Checks that Alex Rivera now gets it.
RELATED: New-ADFineGrainedPasswordPolicy, Get-ADFineGrainedPasswordPolicy, Get-ADUserResultantPasswordPolicy
