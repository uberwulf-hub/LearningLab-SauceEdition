SYNOPSIS: Changes or resets the password of an Active Directory account.
DESCRIPTION:
With -Reset an administrator sets a new password without knowing the old one (a help desk reset). Without -Reset it's a change: the old password is needed too, as when people change their own.
The new password must meet the password policy that applies to the account (the domain policy or a fine-grained one). To make the person pick their own afterwards, run Set-ADUser -ChangePasswordAtLogon $true.
PARAMETER Identity:
The account. Position 0, and takes pipeline input.
PARAMETER Reset:
Sets the password without the old one. Needs the "Reset password" permission on the account.
PARAMETER NewPassword:
The new password, as a SecureString.
PARAMETER OldPassword:
The current password, for a change without -Reset.
EXAMPLE: Set-ADAccountPassword jprice -Reset -NewPassword (Read-Host -AsSecureString "New password")
Resets Jamal Price's password, typed without showing it on screen.
EXAMPLE: Set-ADAccountPassword gkim -Reset -NewPassword (ConvertTo-SecureString "Temp#Pass2026" -AsPlainText -Force); Set-ADUser gkim -ChangePasswordAtLogon $true
Sets a temporary password and makes Grace Kim choose a new one at her next sign-in.
RELATED: Unlock-ADAccount, Set-ADUser, Get-ADUserResultantPasswordPolicy, Enable-ADAccount
