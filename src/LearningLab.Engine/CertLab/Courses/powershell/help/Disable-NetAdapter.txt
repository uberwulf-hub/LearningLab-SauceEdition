SYNOPSIS: Turns a network adapter off.
DESCRIPTION:
Disable-NetAdapter switches an adapter off, as if you unplugged its cable. Its status becomes Disabled and the computer can no longer reach the network through it: pings, name lookups and connections all fail until you run Enable-NetAdapter.

Because this cuts the computer off, try it first with -WhatIf, or add -Confirm to be asked before the change.
PARAMETER Name:
The adapter to turn off, for example Ethernet. Wildcards are allowed.
PARAMETER InputObject:
An adapter object, usually piped from Get-NetAdapter.
PARAMETER PassThru:
Outputs the adapter after the change, so you can see its new status.
PARAMETER Confirm:
Asks before making the change. -Confirm:$false turns the question off.
PARAMETER WhatIf:
Shows what would happen without changing anything.
EXAMPLE: Disable-NetAdapter -Name Ethernet -WhatIf
Shows what the command would do and leaves the adapter alone.
EXAMPLE: Disable-NetAdapter -Name Ethernet -Confirm:$false
Turns off the Ethernet adapter without asking.
EXAMPLE: Get-NetAdapter -Name Ethernet | Disable-NetAdapter -PassThru
Turns the adapter off and shows it with Status Disabled.
NOTES:
On a real PC Windows asks "Are you sure" before disabling an adapter; scripts add -Confirm:$false. On a server you reach over the network (PowerShell remoting or Remote Desktop), disabling its only adapter locks you out and someone must fix it at the console. Practise that here, where nothing breaks for good. CIM-based command, Windows only. Needs an administrator on a real PC.
RELATED: Enable-NetAdapter, Restart-NetAdapter, Get-NetAdapter
