SYNOPSIS: Shows which fine-grained password policy actually applies to a user.
DESCRIPTION:
When a user is covered by several fine-grained password policies, directly or through groups, only one wins. Get-ADUserResultantPasswordPolicy returns that policy.
If it returns nothing, no fine-grained policy applies and the user gets the domain's default policy (Get-ADDefaultDomainPasswordPolicy).
PARAMETER Identity:
The user. Position 0, and takes pipeline input.
PARAMETER Server:
The domain controller to ask.
EXAMPLE: Get-ADUserResultantPasswordPolicy arivera
The policy that rules Alex Rivera's password.
EXAMPLE: Get-ADGroupMember "IT Admins" | ForEach-Object { Get-ADUserResultantPasswordPolicy $_ }
The winning policy for each member of IT Admins.
RELATED: Get-ADFineGrainedPasswordPolicy, Add-ADFineGrainedPasswordPolicySubject, Get-ADDefaultDomainPasswordPolicy
