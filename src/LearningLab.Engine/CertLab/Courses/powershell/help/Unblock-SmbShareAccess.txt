SYNOPSIS: Removes an account's Deny entry from a share.
DESCRIPTION:
Unblock-SmbShareAccess deletes the Deny entry that Block-SmbShareAccess (or -NoAccess on New-SmbShare) added. The account then has whatever its Allow entries give it.
PARAMETER Name:
The share. Position 0.
PARAMETER AccountName:
The user or group.
PARAMETER Force:
Removes without asking.
EXAMPLE: Unblock-SmbShareAccess -Name IT -AccountName "CORP\Helpdesk" -Force
The help desk is no longer blocked from the IT share.
RELATED: Block-SmbShareAccess, Revoke-SmbShareAccess, Get-SmbShareAccess
