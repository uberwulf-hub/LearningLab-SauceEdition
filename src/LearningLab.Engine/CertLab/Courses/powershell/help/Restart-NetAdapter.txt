SYNOPSIS: Turns a network adapter off and on again.
DESCRIPTION:
Restart-NetAdapter disables an adapter and enables it again in one step. On a real PC it is a common first fix when an adapter has stopped working. After it, the adapter's status is Up, even if it was disabled before.
PARAMETER Name:
The adapter to restart, for example Ethernet. Wildcards are allowed.
PARAMETER InputObject:
An adapter object, usually piped from Get-NetAdapter.
PARAMETER PassThru:
Outputs the adapter after the restart.
EXAMPLE: Restart-NetAdapter -Name Ethernet
Restarts the Ethernet adapter.
EXAMPLE: Get-NetAdapter -Name Eth* | Restart-NetAdapter -PassThru
Restarts every adapter whose name starts with Eth and shows them.
NOTES:
On a real PC the network drops for a few seconds while the adapter restarts, so an open remote session may break. CIM-based command, Windows only. Needs an administrator on a real PC.
RELATED: Disable-NetAdapter, Enable-NetAdapter, Get-NetAdapter
