SYNOPSIS: Changes the domain's default password and account lockout policy.
DESCRIPTION:
Set-ADDefaultDomainPasswordPolicy changes the settings that apply to every domain account without a fine-grained policy. Time values are TimeSpans, written as days.hours:minutes:seconds, such as 90.00:00:00 for 90 days or 00:30:00 for 30 minutes.
The lockout observation window can't be longer than the lockout duration.
PARAMETER Identity:
The domain, such as corp.example. Position 0.
PARAMETER MinPasswordLength:
The shortest allowed password.
PARAMETER PasswordHistoryCount:
How many old passwords can't be reused.
PARAMETER ComplexityEnabled:
$true requires three of: capitals, small letters, digits, symbols.
PARAMETER MaxPasswordAge:
How long a password lasts before it must be changed.
PARAMETER MinPasswordAge:
How long before a password may be changed again.
PARAMETER LockoutThreshold:
Wrong passwords before the account locks; 0 means never.
PARAMETER LockoutDuration:
How long a locked account stays locked.
PARAMETER LockoutObservationWindow:
How long until the count of wrong passwords starts again.
PARAMETER ReversibleEncryptionEnabled:
Stores passwords in a reversible form; leave it $false.
EXAMPLE: Set-ADDefaultDomainPasswordPolicy corp.example -MinPasswordLength 12 -LockoutThreshold 5 -LockoutDuration 00:15:00 -LockoutObservationWindow 00:15:00
Longer passwords and a 15-minute lockout after five wrong tries.
EXAMPLE: Set-ADDefaultDomainPasswordPolicy corp.example -MaxPasswordAge 180.00:00:00
Passwords last 180 days.
RELATED: Get-ADDefaultDomainPasswordPolicy, New-ADFineGrainedPasswordPolicy
