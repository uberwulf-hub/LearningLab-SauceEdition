SYNOPSIS: Creates a fine-grained password policy (a password settings object).
DESCRIPTION:
A fine-grained password policy gives some users different password and lockout rules from the domain's default, for example a longer minimum for administrators. It applies only to the users and global security groups it is assigned to (Add-ADFineGrainedPasswordPolicySubject), never to OUs.
When several policies reach one user, the one with the lowest Precedence number wins; a policy assigned to the user directly beats any assigned through groups.
It needs the Windows Server 2008 domain functional level or higher.
PARAMETER Name:
The policy's name. Position 0.
PARAMETER Precedence:
A number above 0; lower wins. Position 1.
PARAMETER MinPasswordLength:
The shortest allowed password.
PARAMETER PasswordHistoryCount:
How many old passwords can't be reused.
PARAMETER ComplexityEnabled:
$true requires complex passwords.
PARAMETER MaxPasswordAge:
How long a password lasts, as a TimeSpan.
PARAMETER MinPasswordAge:
How long before it may be changed again.
PARAMETER LockoutThreshold:
Wrong passwords before the account locks.
PARAMETER LockoutDuration:
How long the lock lasts.
PARAMETER LockoutObservationWindow:
How long until the wrong-password count resets.
PARAMETER ReversibleEncryptionEnabled:
Leave it $false.
PARAMETER Description:
A note about whom it is for.
PARAMETER ProtectedFromAccidentalDeletion:
$true (the default) protects it from deletion.
EXAMPLE: New-ADFineGrainedPasswordPolicy AdminsPSO -Precedence 10 -MinPasswordLength 15 -ComplexityEnabled $true -PasswordHistoryCount 24 -MaxPasswordAge 60.00:00:00 -LockoutThreshold 3 -LockoutDuration 00:30:00 -LockoutObservationWindow 00:30:00
A strict policy for administrators.
EXAMPLE: Add-ADFineGrainedPasswordPolicySubject AdminsPSO -Subjects "IT Admins"
Assigns it to the IT Admins group.
RELATED: Add-ADFineGrainedPasswordPolicySubject, Get-ADFineGrainedPasswordPolicy, Get-ADUserResultantPasswordPolicy
