SYNOPSIS: Checks whether this computer can use a managed service account.
DESCRIPTION:
Test-ADServiceAccount returns True when the computer may retrieve the account's password and the account is installed here, and False (with a warning saying why) when it can't. Run it on the server that runs the service.
PARAMETER Identity:
The account, such as gmsa-web. Position 0, and takes pipeline input.
EXAMPLE: Test-ADServiceAccount gmsa-web
True when SRV1 can use gmsa-web.
EXAMPLE: Invoke-Command -ComputerName SRV1 { Test-ADServiceAccount gmsa-web }
Runs the test on SRV1 from another computer.
RELATED: Install-ADServiceAccount, Get-ADServiceAccount, Set-ADServiceAccount
