SYNOPSIS: Gives the LAPS-managed account a new password now.
DESCRIPTION:
Reset-LapsPassword makes Windows LAPS rotate the managed local administrator account's password at once and back up the new one. The Rotate local admin password remote action in Intune asks for the same.
EXAMPLE: Reset-LapsPassword
A new password, backed up as the policy says.
