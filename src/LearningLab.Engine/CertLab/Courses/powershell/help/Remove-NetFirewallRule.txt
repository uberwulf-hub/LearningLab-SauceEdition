SYNOPSIS: Deletes Windows Firewall rules.
DESCRIPTION:
Remove-NetFirewallRule deletes rules for good. Pick them with -Name, -DisplayName or -DisplayGroup, or pipe them from Get-NetFirewallRule.

Remove the rules you made yourself. For the rules that come with Windows, use Disable-NetFirewallRule instead: once deleted they are hard to get back.

Be careful with wildcards: try -WhatIf first to see which rules match.
PARAMETER Name:
The rule's Name (id). Wildcards are allowed.
PARAMETER DisplayName:
The display name. Wildcards are allowed.
PARAMETER DisplayGroup:
Every rule of one group.
PARAMETER Group:
The group as Windows stores it.
PARAMETER Direction:
Only the Inbound or only the Outbound rules of what you picked.
PARAMETER InputObject:
Rules piped from Get-NetFirewallRule.
EXAMPLE: Remove-NetFirewallRule -Name WebApp-8080
Deletes the rule with that Name.
EXAMPLE: Remove-NetFirewallRule -DisplayName 'Allow ping in'
Deletes a rule by its display name. Several rules may share a display name; all of them go.
EXAMPLE: Remove-NetFirewallRule -DisplayName 'Block*' -WhatIf
Lists the rules a wildcard would delete, without deleting them.
NOTES:
Needs an administrator on a real PC. CIM-based command from the NetSecurity module, Windows only.
RELATED: Disable-NetFirewallRule, New-NetFirewallRule, Get-NetFirewallRule
