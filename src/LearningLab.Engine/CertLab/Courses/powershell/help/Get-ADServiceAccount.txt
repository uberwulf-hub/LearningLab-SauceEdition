SYNOPSIS: Gets managed service accounts from Active Directory.
DESCRIPTION:
Get-ADServiceAccount returns group managed and standalone managed service accounts. Ask for -Properties PrincipalsAllowedToRetrieveManagedPassword to see which computers may use an account.
PARAMETER Identity:
One account, such as gmsa-web. Position 0, and takes pipeline input.
PARAMETER Filter:
A search, such as *.
PARAMETER Properties:
Extra properties to return.
PARAMETER SearchBase:
Only searches below this container.
PARAMETER Server:
The domain controller to ask.
EXAMPLE: Get-ADServiceAccount -Filter * | Select-Object Name, Enabled
Every managed service account.
EXAMPLE: Get-ADServiceAccount gmsa-web -Properties PrincipalsAllowedToRetrieveManagedPassword, DNSHostName
Who may use gmsa-web.
RELATED: New-ADServiceAccount, Set-ADServiceAccount, Test-ADServiceAccount
