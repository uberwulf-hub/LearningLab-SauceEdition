SYNOPSIS: Changes a managed service account, such as which servers may use it.
DESCRIPTION:
Set-ADServiceAccount is mostly used to change -PrincipalsAllowedToRetrieveManagedPassword. The value replaces the whole list, so name every server that should keep access, not only the new one.
A server added to a group that has the right needs a restart (or klist purge -li 0x3e7) before its new group membership counts.
PARAMETER Identity:
The account, such as gmsa-web. Position 0, and takes pipeline input.
PARAMETER PrincipalsAllowedToRetrieveManagedPassword:
The full new list of computers or groups allowed to use it.
PARAMETER Description:
A new description.
PARAMETER PassThru:
Returns the account after the change.
EXAMPLE: Set-ADServiceAccount gmsa-web -PrincipalsAllowedToRetrieveManagedPassword SRV1$, FS1$
SRV1 and FS1 may both use the account.
EXAMPLE: Get-ADServiceAccount gmsa-web -Properties PrincipalsAllowedToRetrieveManagedPassword
Checks the list.
RELATED: Get-ADServiceAccount, New-ADServiceAccount, Install-ADServiceAccount
