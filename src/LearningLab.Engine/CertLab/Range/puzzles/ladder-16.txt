@solution

@walkthrough
Every program inherits a set of environment variables from the shell that starts it:
HOME, USER, PATH, LANG and so on. env (or printenv) lists them all:

    env | sort

One name isn't a usual one: {{VNAME}}. printenv {{VNAME}} (or echo ${{VNAME}}) prints
just its value. It was set by a line in ~/.bashrc, the file your shell reads every time
it starts. Programs leak secrets this way surprisingly often, so on a real system keep
passwords out of the environment.

@hint 15
env lists every environment variable as NAME=value; sort puts them in order so the unusual one is easy to spot. Where do they come from? Look at ~/.bashrc.

@hint 25
