@intro
You are step11. data.bin is not a text file: it is mostly bytes that don't stand for
letters, so cat shows a mess. Somewhere inside are a few readable runs of text. The
password for step 12 is on the one that starts with several = signs and says it is
the password.

@setup

@solution
file data.bin
strings data.bin
strings data.bin | grep ====

@walkthrough
strings reads any file and prints only the runs of four or more printable characters,
skipping the bytes that aren't letters, digits or punctuation:

    strings data.bin | grep ====

Several lines start with ====; only one says it is the password for step 12. Programs,
pictures and disk copies are full of readable bits like these, which is why strings is
one of the first tools people try on an unknown file.

@hint 10
cat prints every byte, readable or not. The command strings prints only the readable stretches of a file. Then grep can keep the lines with ==== in them.

@hint 18
Type: strings data.bin | grep ==== - one line says "the password for step 12 is" followed by the answer.
