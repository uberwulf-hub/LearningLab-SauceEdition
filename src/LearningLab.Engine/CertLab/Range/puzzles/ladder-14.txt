@walkthrough
file looks at the first bytes of a file (its "magic number") and says what it really
is, whatever its name. At each layer:

  - "gzip compressed data": rename it to end in .gz and run gunzip
  - "bzip2 compressed data": rename it to end in .bz2 and run bunzip2
  - "POSIX tar archive": tar -xf unpacks the files inside (ls shows them)
  - "ASCII text": you are there - cat it

Unwrapping this parcel went: {{LAYERS}}.
The habit to learn: never trust a file's name - ask file.

@hint 10
Run file on the parcel after every step: it tells you whether it is gzip, bzip2, tar or plain text. gunzip only unpacks names ending in .gz and bunzip2 names ending in .bz2, so rename (mv) before you unpack. tar -xf unpacks a tar archive whatever it is called.

@hint 18
Repeat: file X; then mv X X.gz && gunzip X.gz (gzip), or mv X X.bz2 && bunzip2 X.bz2 (bzip2), or tar -xf X && ls (tar). Stop when file says ASCII text and cat it.
